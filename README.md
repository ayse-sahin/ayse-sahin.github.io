# Ayşe Şahin — personal website

Static site for GitHub Pages. Upload the contents of this folder to the root of your repository (or a `/docs` folder), then enable Pages in the repo settings.

- `index.html`, `research.html`, `beyond.html`, `cv.html`, `writing.html` — pages
- `nav.dc.html`, `footer.dc.html` — shared header and footer, loaded by every page
- `support.js` — runtime that renders the pages (keep next to the HTML files)
- `assets/` — photos and the animated neuron background
